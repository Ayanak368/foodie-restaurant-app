# Foodie - Restaurant Food Ordering App

Foodie is a responsive restaurant food ordering website built using React and Vite. It allows users to explore food items, search dishes, and filter the menu by category.

## Features

- Responsive homepage with popular dishes
- Menu page with food cards
- Search food by name
- Filter food by category
- Page navigation using React Router
- Reusable components and shared food data

## Technologies Used

- React
- JavaScript
- Vite
- React Router
- HTML
- CSS

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Ayanak368/foodie-restaurant-app.git
   ```

2. Navigate to the project folder:

   ```bash
   cd foodie-restaurant-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
